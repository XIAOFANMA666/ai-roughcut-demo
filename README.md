# AI 粗剪工作台 Demo

出海火车票短视频业务的 AI 粗剪演示：脚本 → 配音 → 素材召回 → 国家/平台规则检查 → 剪映式多轨粗剪 → 自动评分 → 人工精修。

在线访问：https://ethan17461.github.io/ai-roughcut-demo/

数据为模拟数据，视频素材来自 Pexels（免费可商用）。

## 在自己电脑上继续改

```bash
git clone https://github.com/ethan17461/ai-roughcut-demo.git
cd ai-roughcut-demo
```

用浏览器打开 `index.html` 就能看。用 Codex 编辑时，它会先读 `AGENTS.md` 里的项目说明。

要把修改推回这个仓库，需要仓库主人在 Settings → Collaborators 里把你加为协作者。
